## Por qué (STEM)

- El profesorado EIC produce textbooks/ebooks, guías de lab, decks y artículos con alta exigencia de **notación, unidades y citas**.  
- El uso informal de chat suele ser fragmentario y difícil de auditar.  
- La **IA agéntica** (roles, herramientas, HITL) acelera idea → outline → borrador → revisión con supervisión humana.  
- Formato 40 h permite práctica real y avance de un **microartefacto** entre sesiones.

## Qué se obtiene

- **RA top:** distinguir chat vs. agentes; diseñar brief/orquestación; producir outline, secciones, deck o sección IMRyD con verificación; cerrar con agent log + checklist.  
- **Microartefacto EIC:** capítulo STEM corto / deck técnico / sección IMRyD / guía de laboratorio breve + agent log + checklist de calidad.
