# Herramientas (orientativo, agnóstico a proveedor)

> El CADi no depende de un vendor único. Cada edición fijará el stack homologado. **Verificar con CEDDIE / política institucional vigente** cuentas permitidas, residencia de datos y restricciones.

## Categorías

### 1. Asistentes y plataformas de agentes
- Chats con instrucciones de sistema / proyectos.  
- Entornos que permitan roles, herramientas o flujos multi-paso.  
- Criterio de selección: control de instrucciones, historial exportable, opciones de privacidad institucionales.

### 2. Edición y colaboración
- Documentos colaborativos (Word Online, Google Docs, Notion, etc.).  
- Markdown en repositorio (GitHub / GitLab) para versionado de materiales.  
- Criterio: facilidad de diff humano entre `v0` agente y `v1` humano.

### 3. Presentaciones
- PowerPoint, Google Slides, Keynote, o generadores desde markdown (Marp, Slidev, etc.).  
- Criterio: soporte de notas de orador y exportación PDF.

### 4. Gestión de citas y referencias
- Zotero, Mendeley, EndNote u homologados.  
- Criterio: el humano valida cada referencia; la IA no “inventa” entradas bibliográficas.

### 5. Calidad y accesibilidad
- Correctores ortotipográficos.  
- Contrast checkers / revisores básicos de accesibilidad.  
- Checklists del propio CADi (`plantillas/checklist-calidad.md`).

### 6. Videoconferencia y aula
- Microsoft Teams u otra plataforma definida por la edición.  
- Pizarra compartida / breakout rooms para talleres.

## Matriz rápida de uso por sesión

| Sesión | Mínimo necesario |
|--------|------------------|
| 1 | Asistente + documento colaborativo + plantillas |
| 2 | Idem + versionado de secciones |
| 3 | Herramienta de slides + notas |
| 4 | Todo lo anterior + checklist + canal de entrega |

## Buenas prácticas operativas

1. Preferir cuentas institucionales cuando existan.  
2. No pegar datos personales de estudiantes ni material confidencial en herramientas no autorizadas.  
3. Exportar salidas relevantes al agent log.  
4. Separar entornos de experimentación y de materiales “en producción” del curso.

## Lo que este CADi no requiere

- Programar frameworks de agentes desde cero.  
- GPU local ni despliegues cloud propios.  
- Comprar software adicional más allá de lo que la institución ya provea *(salvo decisión explícita de la edición)*.
