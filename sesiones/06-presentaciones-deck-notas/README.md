# Sesión 6 — Presentaciones II — Deck, notas de orador y accesibilidad

**Duración:** 3 horas (en aula)  
**Enfoque:** Deck mínimo viable; notas de orador; variantes clase/conferencia; accesibilidad básica.

## Objetivos de la sesión

Al finalizar, la persona participante:

1. Construye un **deck MV** (8–12 diapositivas) a partir del storyboard.  
2. Genera **notas de orador** alineadas a la voz docente.  
3. Aplica una **mini-checklist de accesibilidad** (contraste, ritmo, alt text conceptual).  
4. Declara el **microartefacto final** EIC hacia el cierre del CADi.  

## Agenda (resumen)

| Bloque | Tiempo | Contenido |
|--------|--------|-----------|
| Recap storyboards | 10 min | Priorizar 8–12 slides |
| Demo deck + notas | 25 min | Voz docente y variantes |
| Accesibilidad | 20 min | Contraste, ritmo, notación legible |
| Taller | 70 min | Deck MV + notas |
| Mini-revisión | 25 min | Checklist accesibilidad |
| Cierre | 20 min | Definir microartefacto final |
