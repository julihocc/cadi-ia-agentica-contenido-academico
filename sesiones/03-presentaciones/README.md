# Sesión 3 — Presentaciones

**Duración:** 3 horas  
**Enfoque:** Objetivos de aprendizaje → arco narrativo → deck + notas de orador.

## Objetivos de la sesión

1. Convertir objetivos de una unidad en un **storyboard** narrativo.  
2. Producir un **deck mínimo viable** (8–12 diapositivas) con densidad visual adecuada.  
3. Generar **notas de orador** alineadas a la voz docente.  
4. Aplicar una revisión rápida (pares o checklist) de claridad y carga cognitiva.

## Agenda (resumen)

| Bloque | Tiempo | Contenido |
|--------|--------|-----------|
| Recap | 10 min | De texto largo a experiencia de clase |
| Narrativa | 25 min | Objetivos → mensajes → arco |
| Demo | 20 min | Storyboard + notas |
| Taller deck | 50 min | 8–12 slides MV |
| Notas y variantes | 30 min | Público clase / conferencia |
| Pares | 25 min | Checklist |
| Cierre | 10 min | Definir microartefacto final |

## Producto esperado

Storyboard + deck MV + notas de orador.
