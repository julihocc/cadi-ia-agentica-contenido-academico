# Sesión 2 — Diseño de briefs, prompts de sistema y orquestación

**Duración:** 3 horas (en aula)  
**Enfoque:** Brief como contrato; prompt de sistema reutilizable; orquestación multi-rol con puntos HITL.

## Objetivos de la sesión

Al finalizar, la persona participante:

1. Completa un **brief de contenido** específico para material EIC.  
2. Diseña un **prompt de sistema** con rol, restricciones, formato y criterio de parada.  
3. Propone un **esquema de orquestación** (2–4 roles) con aprobaciones humanas.  
4. Incluye instrucciones explícitas de no fabricar citas y de señalar incertidumbre.
