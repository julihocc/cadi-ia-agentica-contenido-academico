# Sesión 7 — Artículos I — Estructura, borrador asistido y citas

**Duración:** 3 horas (en aula)  
**Enfoque:** Estructura académica (IMRyD u otra); borrador asistido; citas y datos con verificación humana.

## Objetivos de la sesión

Al finalizar, la persona participante:

1. Estructura un **micro-artículo o sección** (p. ej. IMRyD) o guía de laboratorio breve.  
2. Produce un **borrador asistido** con marcas `[VERIFICAR]` donde corresponda.  
3. Elabora una **lista de citas/datos** a verificar antes de cualquier uso público.  
4. Inicia el **agent log** del pipeline completo.  

## Agenda (resumen)

| Bloque | Tiempo | Contenido |
|--------|--------|-----------|
| Marco artículo | 15 min | IMRyD, audiencia, contribución |
| Demo borrador + citas | 25 min | No fabricar referencias |
| Taller estructura/borrador | 85 min | Micro-sección o guía |
| Lista de verificación | 25 min | Citas y datos |
| Cierre | 20 min | Iniciar agent log; TI |

Detalle de tiempos: [`docs/cronograma.md`](../../docs/cronograma.md).

## Producto esperado

Estructura + borrador con citas/datos a verificar (E7); inicio de agent log.

## Trabajo independiente relacionado

Sesión 8: revisión agéntica, cierre y showcase. TI: completar borrador (C) + agent log (D).
