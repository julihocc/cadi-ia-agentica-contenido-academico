# Sesión 8 — Artículos II — Revisión agéntica, cierre y showcase

**Duración:** 3 horas (en aula)  
**Enfoque:** Agentes de revisión; cierre del microartefacto; agent log + checklist; galería de aprendizajes.

## Objetivos de la sesión

Al finalizar, la persona participante:

1. Aplica **agentes de revisión** (claridad, rigor, sesgos, alineación).  
2. Cierra el **microartefacto EIC** con edición humana final.  
3. Completa **agent log** y **checklist de calidad**.  
4. Comunica aprendizajes transferibles en un showcase breve.  

## Agenda (resumen)

| Bloque | Tiempo | Contenido |
|--------|--------|-----------|
| Agentes de revisión | 15 min | Claridad, rigor, sesgos |
| Demo tres pases + HITL | 25 min | Diff v0→v1 |
| Laboratorio de cierre | 70 min | Integrar pipeline 1–7 |
| Log + checklist | 25 min | Documentación de acreditación |
| Showcase | 25 min | Galería 3–5 muestras |
| Cierre CADi | 10 min | Evaluación y siguientes pasos |

Detalle de tiempos: [`docs/cronograma.md`](../../docs/cronograma.md).

## Producto esperado

Microartefacto + agent log + checklist de calidad (E8 / acreditación).

## Trabajo independiente relacionado

Fin del CADi en aula. Completar TI bloque D si falta (~1.5 h reflexión/checklist).
