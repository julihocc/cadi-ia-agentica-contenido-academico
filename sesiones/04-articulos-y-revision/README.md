# Sesión 4 — Artículos y revisión (cierre)

**Duración:** 3 horas  
**Enfoque:** Estructura de artículo; borrador asistido; agentes de revisión; microartefacto + agent log.

## Objetivos de la sesión

1. Estructurar un **micro-artículo** o sección académica (o consolidar el artefacto elegido).  
2. Aplicar **agentes de revisión** (claridad, rigor, citas, sesgos).  
3. Documentar el proceso en un **agent log** auditable.  
4. Cerrar el CADi con **checklist de calidad** y reflexión transferible.

## Agenda (resumen)

| Bloque | Tiempo | Contenido |
|--------|--------|-----------|
| Marco artículo | 15 min | Estructura y contribución |
| Demo revisión | 25 min | Borrador + agentes |
| Laboratorio | 80 min | Microartefacto integrado |
| Agent log + checklist | 25 min | Documentación |
| Galería y cierre | 25 min | Muestras y evaluación del CADi |

## Producto de acreditación (E4)

Microartefacto (capítulo corto **o** deck **o** sección/artículo) + agent log + checklist de calidad completada.
