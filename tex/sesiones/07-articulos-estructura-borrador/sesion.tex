\textbf{Duración:} 3 horas (en aula)\\
\textbf{Enfoque:} Estructura académica (IMRyD u otra); borrador asistido; citas y datos con verificación humana.

\subsubsection*{Objetivos de la sesión}
Al finalizar, la persona participante:
\begin{enumerate}
\item Estructura un micro-artículo o sección (p.\ ej.\ IMRyD) o guía de laboratorio breve.
\item Produce un borrador asistido con marcas \texttt{[VERIFICAR]} donde corresponda.
\item Elabora una lista de citas/datos a verificar antes de cualquier uso público.
\item Inicia el agent log del pipeline completo.
\end{enumerate}
