\textbf{Duración:} 3 horas (en aula)\\
\textbf{Enfoque:} Agentes de revisión; cierre del microartefacto; agent log + checklist; galería de aprendizajes.

\subsubsection*{Objetivos de la sesión}
Al finalizar, la persona participante:
\begin{enumerate}
\item Aplica agentes de revisión (claridad, rigor, sesgos, alineación).
\item Cierra el microartefacto EIC con edición humana final.
\item Completa agent log y checklist de calidad.
\item Comunica aprendizajes transferibles en un showcase breve.
\end{enumerate}
