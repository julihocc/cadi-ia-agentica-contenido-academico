
Esta carpeta reservará \textbf{muestras anonimizadas} que ilustran el pipeline del CADi (formato \textbf{40\,h}: 8 sesiones en aula + trabajo independiente) para la EIC. En esta versión los ejemplos son descriptivos; las ediciones posteriores pueden añadir archivos reales con consentimiento de autoría.

\subsection*{Qué ilustrarán las muestras}
\begin{enumerate}
\item \textbf{Brief $\rightarrow$ prompt $\rightarrow$ orquestación (sesiones 1--2):} brief de unidad STEM; prompt derivado; esquema multi-rol con HITL.
\item \textbf{Outline y sección (sesiones 3--4):} outline 6--8 nodos; sección v0/v1; diff narrado; reporte de consistencia.
\item \textbf{Storyboard, deck y notas (sesiones 5--6):} tabla storyboard; slides representativas; notas de orador; mini-checklist de accesibilidad.
\item \textbf{Revisión + agent log (sesiones 7--8):} micro-sección IMRyD o guía de lab con \texttt{[VERIFICAR]}; tres pases de revisión; agent log; checklist.
\end{enumerate}

\subsection*{Criterios para publicar un ejemplo}
Consentimiento explícito; sin datos personales ni material confidencial sin autorización; licencia compatible (MIT); etiqueta de edición del CADi.

Hasta que existan archivos reales, use las plantillas y las actividades de cada sesión como guía de trabajo.
