# Ejemplos (placeholders)

Esta carpeta reservará **muestras anonimizadas** que ilustran el pipeline del CADi (formato **40 h**: 8 sesiones en aula + trabajo independiente) para la **Escuela de Ingeniería y Ciencias (EIC)**. En esta versión del repositorio los ejemplos son descriptivos; las ediciones posteriores pueden añadir archivos reales con consentimiento de autoría.

## Qué ilustrarán las muestras

### 1. Brief → prompt de sistema → orquestación (sesiones 1–2)
- Un brief completo de una **unidad de curso STEM** (profesional o posgrado EIC).  
- El prompt de sistema derivado (rol redactor + restricciones de notación/unidades).  
- Un esquema de orquestación multi-rol con puntos HITL.  
- Comentario de “antes/después” mostrando por qué el brief pobre genera ruido.

### 2. Outline y sección de ebook / capítulo de curso (sesiones 3–4)
- Outline de 6–8 nodos con resultados de aprendizaje (capítulo de libro de curso STEM).  
- Una sección `v0` (salida de agente) y `v1` (edición humana).  
- Diff narrado: qué se cortó, qué se verificó (ecuaciones, unidades), qué se añadió.  
- Reporte breve de consistencia (glosario / notación).

### 3. Storyboard, deck y notas de orador (sesiones 5–6)
- Tabla storyboard de 10 slides para un **deck de unidad con notación técnica**.  
- Export o captura de 3 slides representativas (gancho, diagrama/ecuación, cierre).  
- Notas de orador con tiempos y malentendidos anticipados (clase vs. conferencia).  
- Mini-checklist de accesibilidad.

### 4. Revisión de artículo / guía + agent log (sesiones 7–8)
- Micro-sección tipo **IMRyD** (~1000 palabras) o **guía de laboratorio breve**, con marcas `[VERIFICAR]`.  
- Salida de tres pases de revisión (claridad / rigor / sesgo).  
- Agent log llenado de extremo a extremo.  
- Checklist de calidad con dictamen.

## Criterios para publicar un ejemplo aquí

1. Consentimiento explícito del autor.  
2. Sin datos personales ni material confidencial de curso real sin autorización.  
3. Licencia compatible con la del repositorio (MIT) o nota de derechos clara.  
4. Etiqueta de edición del CADi (fecha / cohorte) para trazabilidad pedagógica.

## Cómo contribuir

1. Coloque su paquete en una subcarpeta `ejemplos/YYYY-tema-corto/`.  
2. Incluya un `README.md` de 10–15 líneas que explique qué demuestra.  
3. Enlace el ejemplo desde la sesión correspondiente (01–08) si se usa en vivo.

> Hasta que existan archivos reales, use las [plantillas](../plantillas/) y las actividades de cada sesión como guía de trabajo.
